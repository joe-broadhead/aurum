# Synthetic eval audio (CC0)

Generated by `scripts/generate_eval_audio.py`.

- `silence_1s.wav` — 1 s mono 16 kHz silence (silence false-positive checks)
- `tone_440_1s.wav` — 1 s 440 Hz tone (non-speech / noise marker)

These are **not** speech. Multi-accent licensed speech corpora are external and use the same `evals/corpus.*.json` schema.
