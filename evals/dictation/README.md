# Dictation eval corpus

See [docs/operations/dictation-eval.md](../../docs/operations/dictation-eval.md).

```bash
make eval-dictation-check   # offline: manifest, references, durations, sha256
make eval-dictation         # WER gate (needs a built binary + cached model)
```

- `corpus.v1.json` — 14 clips, 1–11 s, technical terms, hesitations, numbers,
  noise, a quiet microphone, three accents, one silence clip. CC0-1.0 synthetic
  speech; no human recordings.
- `audio/` — 16 kHz mono PCM WAV, generated by
  `scripts/generate_dictation_corpus.sh` (macOS `say`, no ffmpeg).
- `SHA256SUMS` — integrity pins; the harness refuses a mismatch.

Budgets live in the manifest. Change one only with a reviewed reason, and
record it in the changelog.

Reports are written to `evals/reports/_local/` (untracked) so an operator run
does not dirty the tree.
